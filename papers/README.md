# Papers

Each paper uses an isolated workspace. A model may additionally opt into the
guided TRAINING mode `BABYSITTING` with validated terminology, logical-edge,
and evidence-detail-free disclosure assets:

```text
papers/<paper_slug>/
├── README.md       # identity, provenance, and status
├── source/         # immutable paper and supplied source files
├── model/          # pending paper-model reconstruction
├── sessions/       # saved training/reading sessions
└── artifacts/      # extracted text, rendered pages, and other derived files
```

Pending models are provisional snapshots, not continuously maintained assets.
Global harness changes apply to new compilations and human-approved curriculum
records; they do not trigger bulk migration of historical pending models. If an
old pending model is incompatible when requested again, recompile it from the
stored source under the current protocol.

Do not edit files under `source/`. Generated models remain provisional until human approval and promotion into `curriculum/`.
